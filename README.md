# barack-hash.github.io

Portfolio of Yitbarek Tegene (Barack). Live at https://barack-hash.github.io/

Plain static site: `index.html` + `styles.css`, no build step, no JavaScript required to read it.
Machine-readable companions: `projects.json`, `llms.txt`, `sitemap.xml`, JSON-LD in the page head.

To update: edit `index.html` (and mirror the change in `projects.json` / `llms.txt`), commit, push to `main`.
