Nejashi / Sakina

Live Private repo

Multi-tenant SaaS for mosques in Ethiopia: one monorepo serving a marketing site, a staff operator console, an imam console and Sakina, the Amharic-first member app.

A mosque gets prayer and iqamah times, announcements, a moderated community board, a members roster, donations and an Islamic library without running any infrastructure. Multitenant Platform

Public repo

A business-agnostic multi-tenant SaaS foundation where tenant isolation lives inside Postgres, so a bug in a request handler still cannot leak one customer's data to another.

A Fastify modular monolith with a Next.js operator console. Every table has forced row-level security; the app connects only as service roles with no superuser or bypass, and policies read only server-set session variables, never client-supplied claims. On top of that sit billing and entitlement snapshots driven by verified Stripe webhooks, a transactional outbox with exactly-once inbox and dead-letter queue, quarantine-first file storage, a tenant offboarding state machine, support impersonation with real two-person control enforced by the database, and a hash-chained tamper-evident audit ledger. TOTP and WebAuthn verification are implemented in pure Node with no libraries. A private planning repository holds the frozen specs that map one-to-one onto the shipped foundation groups.

  • 13 of 13 foundation groups built; 173 of 173 automated checks pass in one command
  • 15 migrations, about 60 tables and 65 RLS policies, 62 HTTP routes, 6 console pages

Offline Survival LLM

Public repo Hardware

A fully offline survival-reference computer: a Raspberry Pi 5 running a local language model grounded in public-domain survival manuals, driven by a physical keypad and display.

The device answers questions with retrieval-augmented generation over a curated library, and in critical mode for medical, structural or electrical questions it prints the verbatim source passages at temperature zero and warns when only one source supports a claim. Text entry uses old-phone multi-tap decoding on an Arduino. The project is as much a documented build journal as a device: every session, benchmark, wrong assumption and fix is logged, including a fan connector that was not seated, sliding-window attention producing gibberish past two thousand tokens, and a "model is stupid" bug that turned out to be a missing book.

Compute
Raspberry Pi 5 Model B, 8 GB RAM, 128 GB microSD, active cooler, Debian 13
Input and display
Arduino UNO R3, 4×4 membrane keypad, LCD1602, breadboard wiring over serial
Model
Qwen2.5-3B-Instruct Q4_K_M on llama.cpp built from source on-device
Retrieval
sentence-transformers embeddings, FAISS index, BM25 with reciprocal-rank fusion
  • Corpus: 6,136 chunks across 15 manuals, 13 public-domain and 2 free-licensed, with provenance tracked
  • Retrieval regression suite: hit@4 improved from 94% to 100% (34 of 34) after adding hybrid BM25 search
  • Measured on the Pi: 4.7 tokens/s generation, 18.7 tokens/s prompt processing, 4.4 GB RAM in use
  • Thermals: 49–50 °C idle, 69–70 °C plateau under load, never throttled

Pip, a desktop agent

Public repo

A small purple blob that lives at the bottom of your Mac screen, and whose brain is Claude Code running headless on your own subscription.

Pip wanders, naps, can be thrown around, and answers when you talk to it. It can read files, see which app you are in, read the clipboard or take a screenshot, and the status line always says when it looks. Any write, edit, move or shell command shows an Allow or Deny card, and no answer within ninety seconds counts as Deny. Keychains, SSH keys and env files are off-limits entirely. Chores run on a cron schedule with quiet hours and a daily cap.

Quran Hifz Trainer

Live Public repo

An offline-first Quran memorization trainer with a spaced-repetition engine built around the traditional madrasa loops of sabaq, sabqi and manzil.

Pick any of the 114 surahs and drill it word by word through listen, echo, fade, skeleton and blind stages, then chain and link drills. The engine spaces reviews only after seven clean daily days, caps intervals at thirty days, reclaims lost material at a bounded rate, and spreads a missed week across upcoming days instead of stacking forty overdue portions. Pages render as the real Madinah Mushaf with the same line breaks, so the page image in memory stays stable. Everything stays on the device with versioned export and rollback snapshots.

  • 13 test files and about 255 test cases, including one regression test per shipped bug and a 70-day schedule simulation
  • Installable PWA, works fully offline after first load, no backend and no account

Sovereign Architect

Private repo

A local-first life planner that treats a life plan like a project schedule and makes multi-year trade-offs explicit.

You describe where you are, what you could do and the prerequisites between them. The engine runs a real critical-path forward and backward pass, simulates five kinds of capital month by month (financial, temporal, emotional, relational, spiritual), explores orderings under priority heuristics and seeded random trials to build a Pareto front, and runs Monte Carlo risk trials to show how often a plan survives bad luck. The engine is pure TypeScript with no React, DOM or unseeded randomness. Version two shipped with in-product notes on six things version one displayed that were wired to nothing.

  • 104 unit tests over the engine; all data stays in browser storage
